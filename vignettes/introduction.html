Introduction à waterQualSDM

Introduction

waterQualSDM est un package R pour analyser et modéliser la qualité du sol dans les bassins versants agricoles au Maroc. Il permet de :

  • Importer et nettoyer les données environnementales réelles
  • Calculer des variables environnementales spatiales
  • Prédire le Soil Organic Carbon (SOC) avec Random Forest
  • Cartographier les zones vulnérables
  • Générer des recommandations de gestion durable

Données utilisées

  • Variable cible : Soil Organic Carbon (SOC) depuis SoilGrids (0-5cm, g/kg)
  • Occupation du sol : ESA World Cover
  • Topographie : SRTM 30s (altitude et pente)
  • Précipitations : WorldClim 2.5min
  • Zone d’étude : Maroc incluant le Sahara Occidental (source : GADM)

Conclusion

Ce pipeline complet permet de :

  1. Importer des données environnementales réelles
  2. Prétraiter les données pour la modélisation
  3. Modéliser le Soil Organic Carbon avec Random Forest (R² = 0.82)
  4. Évaluer les performances du modèle
  5. Générer des recommandations de gestion durable

Pour la prédiction spatiale complète sur rasters, voir les fonctions predict_water_quality() et calculate_vulnerability_index().
